# Forgelings: App Store In-App Events (seasons)

Written November 12, 2026, for 0.59. Each season in the app can be listed as an In-App Event in App Store Connect (App > In-App Events). Apple's limits: name 30, short description 50, long description 120 characters. Badge: **Special Event**. Purpose: **Appropriate for all users**. Priority: Normal. Event dates: start at 00:00 on the first day and end at 23:59 on the last; publish ("Event start") up to 14 days before. Each needs an event card image (1920 x 1080) and optionally a video; the card should show the Hearth with that season's weather.

Submit each event a few weeks ahead: Apple reviews events like an update. The Japanese localization uses the second column.
