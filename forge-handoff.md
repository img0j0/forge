# Forgelings handoff (start of a new chat)

Current build: **prototype 0.77.0**, shipped November 13, 2026. Live at https://img0j0.github.io/forge/; SHAs for each release are in `RELEASE_PROCESS.md`. Claude page version 130. This file and `RELEASE_PROCESS.md` (dev branch) are the source of truth; `README.md` has the short version. It replaces the 0.16.0 handoff PDF.

**Forgelings** is a cozy pixel-creature daily-habit app in one HTML/JS file. Each day you choose one of three face-down cards, each with one small thing to do. Do it and a one-of-a-kind Forgeling is inked into your journal. Forgelings sit by your Hearth, wander the Map, bring back curios, and get made into charms, relics and 3D statues at the Forge. It runs in English and Japanese, on the web (installable, offline) and as iPhone and Android apps (Capacitor).

## Starting a session

1. Attach the repo with push access (owner `img0j0`, repo `forge`), then clone three branches into `/home/claude`: `forge` (dev: the build workspace), `forge-main` (main: the website mirror) and `forge-ios` (ios-app: Capacitor iPhone and Android, widget code). `tools/ship.sh` expects those names.
2. Setup (about 2 minutes):

       cd forge/i18n && npm install && cd ..          # acorn, needed by pwa.py's Japanese build
       cd qa && npm i axe-core && cd ..               # only for the axe suites
       pip install playwright pillow --break-system-packages   # Chromium is usually preinstalled

3. Read `RELEASE_PROCESS.md` and the latest `history/patchNNN.py`.

## How Hunter works

- **Ship without asking.** Hunter doesn't approve pushes in advance; he tests each release on his iPhone and says what to change. Fixes come afterward.
- **No full test suite before pushing** (`runall.sh`, the journey, the monkeys). Do targeted checks only: screenshots in English and Japanese, by day and at night (lamp), and `qa_axe` when markup changes. A full run belongs before an App Store submission.
- **Ask what the player wants to do, not what the code allows.** Freedom to choose matters to him (twice he couldn't reach the game he wanted). Check a feature can be reached, not only that it works.
- He often plans by voice and approves with a short "Go", "Let's do it" or "Execute the plan". Design docs and canvases on claude.ai record the decisions; the version table below links them.
- After a release, tell him what to test. An installed iPhone copy may keep the old version until it is swiped away and reopened online.

## Design rules

- **Calm.** No streaks, nothing expires, gaps are just gaps, no pull-back nudges. Requests never expire; one open at a time.
- **Fair.** Packs are earned, never sold. Odds are published, with a pity rule. Money (later) is for beauty, keepsakes or support, never progress.
- **Private.** Everything stays on the device (plus the player's own iCloud or Android backup). No accounts, server, tracking or ads.
- **18+** while testing (`MIN_AGE=18`), chosen on purpose to avoid teen-privacy costs.
- **Accessible.** 44 pt tap targets, zero axe violations, contrast checked by day and night, reduced motion respected everywhere, text size setting, spoken descriptions of every Forgeling.
- **Everything works in Japanese.** Every new English string needs Japanese (see below).
- **Unique.** Not a copy of any creature game; every Forgeling is one of a kind. The app is Forgelings, the world is the Forge (never call the app plain "Forge").

## Key technical facts

**Build and patches**
- `work.html` (English, about 1.0 MB) is the source; it equals the current `baseNNN.html` (now `base77.html`). Each release is `history/patchNNN.py`: read the base, count-asserted `rep(old,new)` edits, write `work.html`, `node --check` the extracted script. Bump `VERSION` and `<title>` together; bump `SEEN_V` (now 55) only with a What's New note (eight kept).
- What ships is **`app.html`**: `pwa.py` runs `i18n/build.mjs` over `work.html` (Japanese embedded, about 1.24 MB), then packs `pwa/` (index.html, manifest, `sw.js`, icons, legal pages). The website, `ios-app/forgelings.html`, the Claude page and the project copy are all `app.html`.
- Size budget: 1.15 MB for `work.html` (qa_22, qa_30, qa_301). It is a soft guide: raise it and note it rather than cut a feature Hunter wants. Heavy optional extras load on first use.
- The script runs in a closure, so tests drive the screen and read pixels rather than call functions.

**Japanese (0.57+)**
- `i18n/ja/*.json` holds about 2,700 units; `units.mjs` finds strings and whole templates; `build.mjs` refuses changed placeholders or markup and anything the code compares. After a patch, `cd i18n && node scan.mjs ../work.html` must print no "match nothing" or "untranslated markup" warning (its "to do" count is dev tools and the like). Terms: `i18n/GLOSSARY.md`.
- Write whole sentences as templates, never glued pieces. Never show text saved in one language: save keys or events and write words when shown (`LOC()` for dates, `jaName` for katakana names; the save keeps Latin names).

**Saves and storage**
- localStorage: `forge-app-v1` (the save), `-seen`, `-daily` (safety copy), `-recovery`, `-replaced`; `forge-age-block`, `forge-lang`, `forge-cloud-off`/`forge-cloud-at`, `forge-motion-v1` (what has been seen to move, never in the save), `forge-gift-in`, `forge-visit-in`. The save key, origin and `/forge/` path never change.
- `sanitize()` repairs damaged saves and `migrate()` fills new fields from `fresh()`. A restore must return identical cards (qa_core): don't add default fields to every card.
- One tab at a time (BroadcastChannel); `save()` returns success; an unreadable save opens a recovery sheet.
- Native (0.32, 0.52): saves mirrored to Preferences; iPhone keeps a gzipped iCloud key-value copy (`state.jid` tells journals apart, a different journal is never swapped in silently, `cloudFit` drops the oldest postcards past 880,000 characters); Android uses its own app backup.

**Art**
- Forgelings are drawn on a 40x40 grid (creature coordinates 0..31 plus a 4-pixel margin). New finds are generation 2 (`gen:2`); never change what generation 1 draws. Art changes must pass `creatures/` checks: `same.py` (SAME), `check.py`, `identity.py`, `clip.py`, `bob.py`, `float.py`, `foil.py` (0 problems each). Use `OL(slot)` as the outline test; check any new palette slot against `FOIL3`, `FOIL4` and `OL()`. New spec values need an `FLD` entry (spoken descriptions).
- Curios: `curios/sprites.py` then `tojs.py`. Card backs: `art/cardback72.py`. Icons: `art/make_icons.py` (copy the 1024 and splash to ios-app `art/`). New pixel-art SVGs go through `slim/svgslim.py`; new font weights need a reason.

**UI rules**
- The Scribe (0.76): `scribeTell(from,to,week)` writes whole sentences from moments (no counts in the story); add a moment by pushing `[date, sentence]` onto `hl` so highlights stay in date order. Quotes never repeat an earlier chapter's (`scQuote`).
- The book (0.75): `bookPages()` = cover, contents, per month (oldest first) a chapter title page, its days, its closing page, then the back. Page keys (`bkKey`: c, t, ch:YYYY-MM, d:YYYY-MM-DD, end:YYYY-MM, b) are what the ribbon `state.bookAt` keeps. The book's paper keeps its own ink in every look (`.jbook .zpage`).
- Type scale (0.74): plain text 12 (tab and button captions only), 14, 16, 18, 20 px; handwriting 44 (page titles), 36 (reveals), 28 (section headings), 22 (everything else). Use these sizes; card faces and icons keep their fitted sizes. Inputs stay at 16 px or more (iPhone zooms on smaller).
- How-to lines that stop being useful after a few days go through `tipFade(key, el)` after render (shown on the first five days seen; device-level `forge-tips-v1`), not into the template.
- Field journal look (0.46+): paper by day, lamplight (`data-page="lamp"`) at dusk, night or Dark; Plain keeps the old flat look. Three hands: your words handwritten (`--hand`, Caveat 700, never under 20 px), the world's words in italic world ink, the Forge's stamps in VT323. Journal variables are `--j…` (never reuse `--paper` or `--stamp`).
- Motion (0.48, 0.72): under two seconds, a tap skips, base CSS is the final state so reduced motion leaves things still and finished. Since 0.72 Rare and up build up before the turn (`chargeThen`); everything else times the same for every rarity.
- Keep pages short (qa_43 caps page lengths): new features go in sheets (`openHSheet`, `jSheet`, `.csheet`). The Map never shows counts or progress bars.
- Check class names before adding one: taken include `.fgh`, `.jstamp`, `.rib`, `.face`, `.back`, `.dcard`. CSS keyframe names are global.
- Games: play pieces draw in front of the Forgeling, never on the fire; check new game art at 320 wide and test with real touch (qa_242 style).
- Tabs are Today, Hearth, Binder, Map, Settings. Never send players to "the Chronicle".

**World**
- The world calendar is a pure function of the date (epoch 2026-01-01); ERAS and EVENTS are append-only, so history never changes. Seasons (0.59) are seven fixed real-calendar windows, stamped once a year.
- Embers are derived from history, not stored. Bond stories and Hearth furnishings are derived too.
- Known tradeoff: setting the clock back lets someone farm days (no server).
